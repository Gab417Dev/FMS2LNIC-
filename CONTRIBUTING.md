# Contributing

First of all, thanks for considering it!

## What i'd love to receive
 - Corrections of wrong
 - Suggestions
 - Pointers to good resources
 - Bug reports
 - Small improvements

## What's less useful
 - Rewriting the whole thing the "right way" without explaining why
 - Huge refactors or style-only changes
 - Adding big dependencies or frameworks
 - Rewriting the whole thing in rust

## Explain your changes
In every issue/pr explain:
 1. **What** you changed/you think its wrong
 2. **Why** the original was a problem
 3. **Why** your version is better
 4. **How** you tested it

## How to contribute

### Issues
Open an issue describing the problem or suggestion, include the file/line, your OS and compiler/library versions
and how to reproduce it if it's a bug.

### Pull request
 1. Fork the repo and create a branch with a descriptive name
 2. Make your change, one topic per pr
 3. Make sure it builds and run
 4. Open the PR and explain like described above
